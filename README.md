# Пасека «Гнездино» — сайт-визитка

Одностраничный статический сайт. Человек получает банку мёда, сканирует QR на крышке,
попадает сюда и узнаёт, откуда этот мёд: что за место, что за пасека, как связаться.
Ни бэкенда, ни корзины, ни каталога — только фронтенд.

## Что где лежит

```
site/
├── index.html                # вся разметка и тексты
├── css/style.css             # стили; цвета и размеры — в переменных в начале файла
├── js/main.js                # меню, подсветка раздела, просмотр фотографий
└── img/
    ├── logo.jpg              # логотип (он же картинка для превью в мессенджерах)
    ├── favicon-honeycomb.png # иконка вкладки
    ├── gnezdino.jpg          # фото в разделе «Место» (указатель на деревню)
    └── gallery/              # фотографии: галерея + фон первого экрана и контактов
        ├── hives-path.jpg
        ├── hives-closeup.jpg
        ├── sot-honey.webp
        ├── sot-honey-bank.jpg
        └── bank-honey.webp
```

Внешние зависимости — шрифт Onest (Google Fonts) и Bootstrap (сетка и иконки) с jsDelivr.
Сборки и npm нет: файлы открываются двойным кликом.

## Как устроена вёрстка

- Стили написаны «от телефона»: базовые правила — для узкого экрана, для компьютера
  дописано через `min-width`.
- Высоту разделов больше не растягиваем на весь экран — её определяет содержимое.
  На весь экран остался только первый (`.hero`).
- На телефоне в «Месте» и «Пасеке» фото стоит над текстом (в «Месте» оно поднимается
  через `order`), на компьютере — сбоку и «прилипает» при прокрутке.
- Первый экран и фото раздела «Пасека» на телефоне и компьютере используют разные
  кадры: вертикальный и горизонтальный (см. `.hero-photo` и `.photo-apiary`).
- Галерея — мозаика из пяти снимков. Кто где стоит, задано в CSS по классам
  `shot-path`, `shot-hives` и т. д.; порядок в HTML — это порядок листания в просмотре.
- Просмотр фото: закрывается по Esc, по тапу на фон и крестиком; листается стрелками
  на клавиатуре, кнопками и свайпом.

## Публикация на GitHub Pages

1. Создайте репозиторий и положите в его корень содержимое папки `site/`
   (`index.html` должен лежать в корне, а не во вложенной папке).
2. Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)`.
3. Через минуту сайт будет по адресу `https://<логин>.github.io/<репозиторий>/`.
4. Свой домен (гнездино-пасека.рф) подключается там же: Settings → Pages → Custom domain.
   У регистратора добавляется запись CNAME на `<логин>.github.io`.

## Что заменить или проверить

- **Почта.** В контактах стоит заглушка `info@example.com` — впишите настоящую или
  удалите этот пункт (в `index.html` рядом с ним стоит TODO).
- **Превью в мессенджерах.** В `og:image` прописан адрес
  `https://гнездино-пасека.рф/img/logo.jpg` (в разметке — в punycode). Если домен
  будет другим, поправьте адрес в `<head>`.
- **Фотографии.** Пока в галерее только два настоящих снимка ульев — они же используются
  на первом экране и в разделе «Пасека». Остальные три — временные, взяты из
  открытых источников. Когда появятся свои, меняйте `src` и `data-src` в блоках `.shot`
  и подписи к ним. Фон первого экрана — правило `.hero-photo`, фото разделов —
  `.photo-place` и `.photo-apiary`, фон контактов — `.contacts`.
- **Раздел «Мёд».** Его в разметке нет, ссылки на него из меню и подвала убраны.
  Если понадобится — добавьте `<section id="honey">` и пункт в оба меню.
