# Пасека «Гнездино» — сайт-визитка

Одностраничный статический сайт. Человек получает банку мёда, сканирует QR на крышке,
попадает сюда и узнаёт, откуда этот мёд: что за место, что за пасека, как связаться.
Ни бэкенда, ни корзины, ни каталога — только фронтенд.

## Структура

```
site/
├── index.html      # вся разметка страницы
├── css/style.css   # стили, все цвета и размеры — в переменных в начале файла
├── js/main.js      # меню, подсветка раздела, просмотр фотографий крупно
└── img/logo.jpg    # логотип (он же favicon и картинка для превью в мессенджерах)
```

Внешние зависимости — только шрифт Onest с Google Fonts. Ни Bootstrap, ни jQuery, ни сборки:
файлы можно открыть двойным кликом и они сразу работают.

## Публикация на GitHub Pages

1. Создайте репозиторий и положите в его корень содержимое папки `site/`
   (`index.html` должен лежать в корне, а не во вложенной папке).
2. Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)`.
3. Через минуту сайт будет доступен по адресу `https://<логин>.github.io/<репозиторий>/`.
4. Свой домен (гнездино-пасека.рф) подключается там же, в Settings → Pages → Custom domain:
   у регистратора домена добавляется запись CNAME на `<логин>.github.io`.

## Что заменить перед публикацией

- **Фотографии.** Сейчас стоят временные снимки с Wikimedia Commons, они подгружаются
  по прямым ссылкам. Свои фото положите в `img/` и подставьте пути:
  в галерее — атрибуты `src` и `data-src` у блоков `.shot` в `index.html`,
  фоновые — правила `.hero-photo`, `.photo-place`, `.photo-apiary`, `.contacts` в `style.css`.
- **Текст про деревню** в разделе «Место» — сейчас там заглушка курсивом.
- **Годы в таймлайне** раздела «Пасека»: 1955 взят с логотипа, остальное нужно уточнить.
- **Контакты** в разделе «Как получить банку» и телефон `+7 000 000-00-00` — заглушки.
- **Сорта мёда** — оставлены четыре типовых, поправьте под свои сборы.

## Мелочи, которые уже учтены

- Адаптив: на телефоне меню сворачивается в кнопку, галерея перестраивается в две колонки.
- Клавиатура: по сайту можно ходить табом, просмотр фото закрывается по Esc,
  листается стрелками.
- Фотографии в галерее грузятся лениво (`loading="lazy"`), чтобы страница открывалась быстро.
